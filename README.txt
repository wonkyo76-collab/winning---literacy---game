위닝줄넘기 문해력게임 V11 PWA 배포판

구성
- index.html : 게임 본체
- manifest.webmanifest : 휴대폰 앱 설치 정보
- sw.js : 오프라인 실행용 서비스워커
- icon-192.png / icon-512.png : 앱 아이콘

배포 방법
1. 이 폴더 안의 파일 5개를 GitHub 저장소의 최상위 폴더에 업로드합니다.
2. GitHub Pages를 활성화합니다.
3. 생성된 https 주소를 학생들에게 QR코드로 배포합니다.
4. 학생은 QR 접속 후 Android/Chrome에서는 '앱 설치' 또는 게임의 📲설치 버튼,
   iPhone/Safari에서는 공유 버튼 → '홈 화면에 추가'를 선택합니다.
5. 최초 1회 온라인 접속 후 게임 파일이 캐시에 저장되면 오프라인에서도 실행할 수 있습니다.

주의
- 브라우저 데이터를 삭제하거나 앱을 제거하면 로컬 학습기록도 삭제될 수 있습니다.
- 다른 휴대폰으로 기록이 자동 동기화되지는 않습니다.
